# HTML 버전 실행과 개인정보 보호

## 제공 형태

이 프로젝트는 두 버전을 함께 유지한다.

1. Windows 독립 실행 버전: `NpsSimulator.exe`
2. HTML 버전: `web` 폴더의 브라우저 앱

HTML 버전도 계산과 정책 파일 검증을 브라우저 내부에서 수행한다. 개인정보를 받는 API, 데이터베이스, 계정, 분석 도구를 사용하지 않는다.

외벌이 가정에서는 `배우자 있음 · 유족연금 계산`은 켜고 `배우자 본인 국민연금 있음`만 끈다. 그러면 배우자의 본인 노령연금은 0원으로 처리하지만 가입자인 배우자가 먼저 사망한 뒤의 유족연금은 계속 계산한다.

## 개발용 로컬 실행

Node.js 22.13 이상이 설치된 PC의 PowerShell에서 실행한다.

```powershell
cd web
npm install
npm run dev
```

화면에 표시된 `http://localhost:3000`을 브라우저에서 연다. 프로덕션 검증은 `npm run build`로 한다.

## 암호화 세션 저장

- 저장을 누르기 전에는 입력값을 브라우저 저장소에 기록하지 않는다.
- 저장을 선택하면 Web Crypto API의 AES-256-GCM으로 암호화한 JSON만 `sessionStorage`에 기록한다.
- 암호 키는 사용자 암호에서 PBKDF2-SHA256 250,000회로 만들며 암호 자체와 복호화 키는 저장하지 않는다.
- 같은 탭을 새로 고칠 때 사용자가 암호를 다시 입력하면 복원할 수 있다.
- 탭 또는 브라우저를 닫으면 해당 탭의 `sessionStorage`가 삭제된다.
- 악성 브라우저 확장, 감염된 운영체제, 사용자가 연 상태에서의 화면 캡처까지 방어하는 기능은 아니다.

## 정책 파일

HTML 버전은 다음 두 형식을 읽는다.

- HTML 간소 정책 스키마 `1.0`
- Windows 버전의 전체 정책 팩 스키마 `1.0.0`

따라서 Windows 버전의 `policy-pack.json`을 HTML 버전의 `정책·보안 관리 > 정책 JSON 적용`에서 그대로 선택할 수 있다. HTML 버전은 자신이 사용하는 규칙만 읽고 알 수 없는 실행 코드나 스크립트를 실행하지 않는다.

AI에 정책 수정을 맡길 때는 개인 입력값이나 암호화 세션 파일을 보내지 말고 공개 정책 JSON과 공식 자료만 전달한다. 현재 적용 정책은 화면에서 내려받을 수 있다.

## 배포 점검

- 제3자 분석·광고·로그 수집 스크립트를 추가하지 않는다.
- HTTPS에서만 운영한다.
- 배포 전 `npm run build`와 정책 경계 테스트를 통과시킨다.
- 호스팅 운영자가 정적 파일과 접속 로그를 볼 수는 있으나, 이 앱은 입력값을 네트워크 요청에 싣지 않는다.
