# HTML 실행과 개인정보 보호

## 제공 형태

이 프로젝트는 `web/` 폴더의 브라우저 애플리케이션만 제공합니다. 개발 서버로 실행하거나, 빌드한 단일 HTML 파일을 Chrome 또는 Edge에서 직접 열 수 있습니다.

계산과 정책 검증은 브라우저 내부에서 수행합니다. 개인정보를 받는 API, 데이터베이스, 계정 또는 분석 도구를 사용하지 않습니다.

## 개발용 로컬 실행

Node.js 22.13 이상이 설치된 환경에서 실행합니다.

```powershell
cd web
npm install
npm run dev
```

단일 HTML은 `npm run build:standalone`으로 생성합니다.

## 저장하지 않은 상태

- 초기 입력값은 서버나 브라우저 저장소에 자동 저장하지 않습니다.
- 입력 후 저장하지 않은 변경이 있으면 화면 상단에 경고 상태를 표시합니다.
- 저장되지 않은 변경이 있는 상태에서 탭을 닫거나 새로고침하면 브라우저가 확인 경고를 표시합니다.

## 암호화 JSON 파일

- 사용자가 파일명, 저장 위치와 암호를 직접 선택합니다.
- Web Crypto API의 AES-256-GCM으로 전체 프로필을 암호화합니다.
- 키는 8자 이상의 사용자 암호에서 PBKDF2-SHA256 250,000회로 생성합니다.
- 암호와 복호화 키는 저장하지 않습니다.
- 파일을 불러올 때만 사용자가 암호를 다시 입력합니다.
- 지원 브라우저에서는 불러온 파일과 현재 탭을 연결해 `Ctrl+S`로 같은 파일에 저장할 수 있습니다.
- 브라우저가 직접 파일 쓰기를 지원하지 않으면 같은 파일명으로 다시 내려받습니다.

## 탭 임시 저장

- 사용자가 선택한 경우에만 암호화 데이터를 현재 탭의 `sessionStorage`에 기록합니다.
- 암호화 방식과 키 생성 방식은 JSON 파일 저장과 같습니다.
- 탭 또는 브라우저를 닫으면 해당 탭의 임시 저장은 사라집니다.

## 평문 산출물 주의

AI 상담용 Markdown, 인쇄물과 PDF에는 계산 결과와 재무 정보가 평문으로 포함될 수 있습니다. 외부 AI나 다른 사람에게 전달하기 전에 반드시 내용을 확인해야 합니다.

악성 브라우저 확장, 감염된 운영체제, 사용자가 파일을 연 상태의 화면 캡처까지 방어하는 기능은 아닙니다.

## 정책 파일

연금·부동산 정책 업데이트는 앱이 생성하는 Markdown 요청서와 고정 JSON 블록을 사용합니다. 앱은 AI가 작성한 일반 문장을 실행하지 않으며, 정해진 표식 안의 정책 데이터만 스키마·숫자 범위·출처 형식에 따라 검사합니다.
