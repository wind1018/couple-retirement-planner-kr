# AI를 이용한 연금·부동산 정책 업데이트

이 문서는 공개된 공식 자료를 바탕으로 연금과 부동산 정책 데이터를 갱신하는 현재 웹 앱의 절차를 설명합니다.

## 전체 흐름

1. `정책·보안 관리`에서 **AI 업데이트 요청 MD**를 저장합니다.
2. 웹 검색이 가능한 AI에 해당 Markdown을 첨부하고 공식 자료 기준 업데이트를 요청합니다.
3. AI가 반환한 Markdown을 **AI 결과 MD 불러오기**로 선택합니다.
4. 앱이 고정 표식 안의 JSON 정책 블록과 출처를 검사합니다.
5. 변경 요약·정책 ID·시행일·출처를 사람이 확인합니다.
6. **두 정책 적용**을 눌러 연금과 부동산 정책을 함께 반영합니다.
7. 문제가 있으면 **문제 발생 시 기본값 복원**을 사용합니다.

## AI에 전달해도 되는 정보

- 앱이 생성한 정책 업데이트 요청 Markdown
- 법령, 고시, 국민연금공단과 과세기관 등 공식 자료
- 공개된 제도 정보와 기준일

다음 정보는 전달하지 않습니다.

- 암호화 JSON 프로필과 암호
- 이름, 생년월일, 소득, 자산·부채, 연금액
- AI 상담용 개인 분석 Markdown
- 브라우저 기록, 파일 경로 또는 앱 로그

## 검증 원칙

- Markdown의 일반 문장은 실행하지 않습니다.
- 정해진 표식 안의 JSON 데이터만 읽습니다.
- 스키마, 필수 항목, 숫자 범위와 HTTPS 출처를 확인합니다.
- 연금 정책과 부동산 비용 정책을 한 묶음으로 미리 보여준 뒤 사용자가 적용합니다.
- AI 결과는 참고 초안이며 시행일과 공식 출처를 사람이 최종 확인해야 합니다.

## 정책과 개인 분석의 구분

정책 업데이트 요청 Markdown에는 공개 정책만 포함됩니다. 반대로 **AI 상담용 MD 저장**으로 생성한 문서는 개인 입력과 계산 결과를 포함할 수 있으므로 정책 업데이트 용도로 사용하지 않습니다.
