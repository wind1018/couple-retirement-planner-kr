# 노후자금 시뮬레이터

한국 부부의 국민·기초·개인·퇴직·유족연금과 생활비, 자산·부채, 은퇴 이후 현금흐름을 한 화면에서 비교합니다.

모든 계산은 브라우저 안에서 수행합니다. 입력값을 서버로 보내지 않으며, 사용자가 선택한 경우에만 암호화 JSON 파일 또는 현재 탭의 `sessionStorage`에 저장합니다.

## 어떤 파일이 필요한가

| 경로 | 용도 | 일반 사용자에게 필요 |
|---|---|---|
| [`release/retirement-fund-simulator.html`](release/retirement-fund-simulator.html) | 실제 실행·배포 파일 | **필요** |
| `web/` | 화면이나 계산 로직을 수정하고 새 HTML을 만드는 개발 소스 | 불필요 |
| `docs/` | 개인정보 보호와 정책 업데이트 설명 | 선택 사항 |

실제 사용과 전달에는 `release/retirement-fund-simulator.html` 한 파일이면 충분합니다. 저장소 전체나 `web` 폴더를 함께 내려받거나 전달할 필요가 없습니다.

## HTML 파일 사용 방법

1. [`release/retirement-fund-simulator.html`](release/retirement-fund-simulator.html)을 내려받습니다.
2. `.html` 확장자를 유지한 채 파일을 Chrome 또는 Edge로 엽니다.
3. 자신의 조건을 입력하고 **지금 다시 계산**을 눌러 결과를 확인합니다.
4. 입력 내용을 나중에 다시 사용할 경우 앱에서 암호화 JSON 파일로 저장합니다. 다음 사용 시 같은 HTML에서 JSON 파일을 불러오고 암호를 입력하면 됩니다.

설치, 회원가입, 인터넷 연결, 웹 서버 실행은 필요하지 않습니다. 일반 사용자는 Node.js나 `npm` 명령을 사용할 필요가 없습니다. HTML만 전달할 때는 사용자의 입력값이 포함되지 않으며, 별도로 만든 JSON·AI 상담용 Markdown·PDF를 공유할 때는 개인정보와 재무정보가 포함될 수 있으므로 주의해야 합니다.

## 주요 기능

- 본인·배우자의 국민연금 수급 시점과 조기·정상·연기 수령 비교
- 외벌이·국민연금 미가입 배우자와 유족연금 자동 선택 계산
- 기초연금, 개인연금, 퇴직연금, 임대·기타 반복소득 통합
- 은퇴 전 근로소득과 은퇴·연금 개시·수령 종료 사건별 현금흐름 비교
- 국가 생활비 기준 및 노후 부부 최소·적정 생활비 비교
- 현금·금융자산 운용수익과 생활비 부족분 자동 인출
- 부동산 매각·주거 이전·거래비용·보유세의 러프 계산
- 자산과 연결된 대출의 매각 시점 자동 상환
- 주요 사건별 자산·부채·소득 비교와 부족재원 충당 분석
- AI 상담용 Markdown 보고서 생성
- AES-256-GCM 암호화 JSON 저장·불러오기와 `Ctrl+S` 연결 저장
- 인쇄 및 PDF용 보고서 레이아웃

## `web` 소스를 수정해 배포 파일 다시 만들기

`web/`은 프로그램의 화면, 계산 엔진, 스타일, 테스트와 단일 HTML 생성 스크립트를 보관합니다. 프로그램을 수정하거나 새 배포 파일을 생성할 때만 필요하며 일반 사용자는 실행하지 않습니다.

소스를 수정한 개발자는 Node.js 22.13 이상에서 저장소 루트를 기준으로 다음 명령을 실행합니다.

```powershell
cd web
npm install
npm run build
```

빌드가 완료되면 수정 내용이 반영된 `release/retirement-fund-simulator.html`이 새로 생성됩니다. 최종 배포 대상은 다시 이 HTML 한 파일이며, 별도의 웹 서버용 배포판은 만들지 않습니다.

## 저장과 개인정보 보호

- 저장 전에는 입력값을 브라우저 저장소에 기록하지 않습니다.
- JSON 파일은 Web Crypto API의 AES-256-GCM으로 암호화합니다.
- 키는 8자 이상의 암호에서 PBKDF2-SHA256 250,000회로 생성합니다.
- 암호와 복호화 키는 파일이나 브라우저 저장소에 기록하지 않습니다.
- 임시 저장은 현재 탭의 `sessionStorage`만 사용하며 탭을 닫으면 사라집니다.
- AI 상담용 Markdown, 인쇄물과 PDF는 평문일 수 있으므로 공유 전에 내용을 확인해야 합니다.

자세한 내용은 [HTML 실행과 개인정보 보호](docs/HTML_VERSION_PRIVACY.md)를 참고하세요.

## 정책 업데이트

연금과 부동산 정책은 실행 코드와 분리된 데이터로 관리합니다. 앱에서 AI 업데이트 요청 Markdown을 내려받아 공식 자료를 확인할 수 있는 AI에 전달하고, 결과 Markdown을 다시 불러와 검증한 뒤 적용할 수 있습니다.

자세한 흐름은 [AI 정책 업데이트](docs/POLICY_UPDATE_WITH_AI.md)를 참고하세요.
