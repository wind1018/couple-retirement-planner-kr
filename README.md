# 노후자금 시뮬레이터

한국 부부의 국민·기초·개인·퇴직·유족연금과 생활비, 자산·부채, 은퇴 이후 현금흐름을 한 화면에서 비교합니다. 최종 배포물은 설치나 웹 서버가 필요 없는 `retirement-fund-simulator.html` 단일 파일입니다.

모든 계산은 브라우저 안에서 수행합니다. 입력값을 서버로 보내지 않으며, 사용자가 선택한 경우에만 암호화 JSON 파일 또는 현재 탭의 `sessionStorage`에 저장합니다.

## 주요 기능

- 본인·배우자의 국민연금 수급 시점과 조기·정상·연기 수령 비교
- 외벌이·국민연금 미가입 배우자와 유족연금 자동 선택 계산
- 기초연금, 개인연금, 퇴직연금, 임대·기타 반복소득 통합
- 은퇴 전 근로소득과 은퇴·연금 개시·수령 종료 사건별 현금흐름 비교
- 국가 생활비 기준 및 노후 부부 최소·적정 생활비 비교
- 현금·금융자산 운용수익과 생활비 부족분 자동 인출
- 부동산 매각·주거 이전·거래비용·보유세의 러프 계산
- 자산과 연결된 대출의 매각 시점 자동 상환
- 주요 사건별 자산·부채·소득 비교와 부족재원 충당 분석
- AI 상담용 Markdown 보고서 생성
- AES-256-GCM 암호화 JSON 저장·불러오기와 `Ctrl+S` 연결 저장
- 인쇄 및 PDF용 보고서 레이아웃

## 최종 배포 파일

`release/retirement-fund-simulator.html`만 전달하면 됩니다. 받은 사람은 Chrome 또는 Edge에서 파일을 직접 열어 자신의 조건을 입력하고 계산할 수 있습니다.

## 소스 미리보기

Node.js 22.13 이상이 필요합니다.

```powershell
cd web
npm install
npm run dev
```

이 명령은 개발 중 화면을 확인하기 위한 Vite 미리보기이며 서버용 배포물을 생성하지 않습니다.

## 검사와 단일 HTML 빌드

```powershell
cd web
npm run lint
npm test
npm run build
```

`npm run build`와 `npm run build:standalone`은 모두 `release/retirement-fund-simulator.html` 한 파일을 생성합니다.

## 저장과 개인정보 보호

- 저장 전에는 입력값을 브라우저 저장소에 기록하지 않습니다.
- JSON 파일은 Web Crypto API의 AES-256-GCM으로 암호화합니다.
- 키는 8자 이상의 암호에서 PBKDF2-SHA256 250,000회로 생성합니다.
- 암호와 복호화 키는 파일이나 브라우저 저장소에 기록하지 않습니다.
- 임시 저장은 현재 탭의 `sessionStorage`만 사용하며 탭을 닫으면 사라집니다.
- AI 상담용 Markdown, 인쇄물과 PDF는 평문일 수 있으므로 공유 전에 내용을 확인해야 합니다.

자세한 내용은 [HTML 실행과 개인정보 보호](docs/HTML_VERSION_PRIVACY.md)를 참고하세요.

## 정책 업데이트

연금과 부동산 정책은 실행 코드와 분리된 데이터로 관리합니다. 앱에서 AI 업데이트 요청 Markdown을 내려받아 공식 자료를 확인할 수 있는 AI에 전달하고, 결과 Markdown을 다시 불러와 검증한 뒤 적용할 수 있습니다.

자세한 흐름은 [AI 정책 업데이트](docs/POLICY_UPDATE_WITH_AI.md)를 참고하세요.

## 정확도와 한계

이 프로그램의 연금·세금·부동산 비용 계산은 사용자가 입력한 예상액과 공개 정책을 바탕으로 한 참고용 시뮬레이션입니다. 실제 수급 자격, 세금, 보험료, 부동산 비용과 연금액은 신청·거래 시점의 법령 및 국민연금공단·금융기관·과세기관의 산정 결과가 우선합니다.
