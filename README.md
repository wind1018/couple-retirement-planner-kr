# 부부 연금 종합 시뮬레이터

외벌이 등으로 배우자가 국민연금에 가입하지 않은 경우, 배우자 영역의 `국민연금 가입/예상연금 있음` 체크를 끄면 가입기간·예상연금·납부액 입력 없이 계산할 수 있습니다. 미가입자의 본인 노령연금은 0원으로 처리하며 유족연금 계산은 유지됩니다. 배우자 자체를 입력하지 않는 1인 계산은 `배우자(B) 포함`을 끄면 됩니다.

Windows에서 웹 서버나 외부 브라우저 없이 실행되는 로컬 전용 앱과, 같은 목적의 브라우저 HTML 앱을 함께 제공한다. 두 버전 모두 개인정보를 서버에 저장하지 않으며 결과를 HTML 보고서 형태로 표시한다.

## 현재 구현 범위

- 생년월일은 `19750222`와 같은 8자리 숫자로 입력
- NPS 앱의 세전 예상 노령연금·총 예상납부액·가입기간을 그대로 입력
- 가입기간은 `[1999]년 [04]월 ~ [2035]년 [02]월 총 [418]개월` 형태의 숫자 전용 칸으로 입력
- 가입기간의 연·월 칸은 자릿수가 채워지면 다음 입력칸으로 자동 이동
- 생년월일과 정책 파일의 출생연도별 수급연령으로 정상 수급 시작월(생일 다음 달)을 자동 계산
- 날짜 범위보다 공단의 총 예상 가입개월을 우선하여 이직·프리랜서·납부예외 등 가입 공백 보존
- 달력상 공백개월을 추납 후보로 제시하되 사용자가 수정하고 ‘공단 확인 완료’를 체크해야 전략에 반영
- 현재 월 보험료를 모르면 총 예상납부액 ÷ 총 예상 가입개월을 비용 계산용 월평균으로 사용
- 세전 월 예상연금 입력 시 정책 파일의 연금소득공제·세율로 세후 월액을 자동 추정
- 모든 원 단위 입력칸은 입력 즉시 천 단위 쉼표를 표시하고, 본인·배우자 표는 동일 행 높이로 정렬
- 전략 보고서 상단에서 본인·배우자의 임의계속가입 기간(0~5년), 월 납입 예상액, 조기·정상·연기 수령 나이를 한 번에 입력
- 수령 나이는 정상 수급 나이 전후 5년을 선택 바로 표시하며 정상 나이에 `(기본)` 표시
- 임의계속가입 종료 나이보다 이른 수령 선택지는 자동으로 비활성화
- 현재 월 보험료가 없으면 공단 총 예상납부액의 월평균을 60세까지 납부 비용 추정에 사용
- 임의계속가입 월 납입 예상액은 사용자가 실제 감당할 금액을 직접 입력하고, 해당 금액과 추가 가입개월로 연금 증가분을 Anchor Mode 추정
- 같은 선택 전략을 유족연금 시뮬레이션에도 자동 적용하여 두 화면에서 조건이 달라지는 문제 방지
- 정상수령 대비 손익이 뒤집히는 나이와 75·80·85·90·95세 누적 차이를 한 장의 HTML 보고서로 표시
- 일반 전략과 유족연금 보고서 모두 `연도·본인 나이/월액·배우자 나이/월액·부부 월 합산` 표 제공
- 상대방이 아직 연금을 받기 전이거나 사망한 이후에는 해당 연도의 월액을 0원으로 명확히 표시
- 월별 입출금 원장은 화면에서 제외하고 전략명·추가납부액·수령시작월·월연금·생존 나이별 손익 중심으로 요약
- 사망 시나리오 및 본인 노령연금/유족연금 중복조정
- 외벌이로 배우자 본인 국민연금이 0원이어도 배우자 생년월일·사망 나이를 유지하고, 가입자인 배우자 사망 후 유족연금 전액 수령 시나리오 계산
- 별도 유족연금 탭에서 본인·배우자 예상 사망 나이를 각각 입력하고 실제 생년월일 기준 사망 순서 자동 판정
- 부부 모두 생존 시 월 합산, 첫 사망 다음 달 월 합산, 본인연금·유족연금 중복조정 후 월 합산을 큰 금액 카드로 구분
- 본인 노령연금 + 유족연금 정책 추가율과 유족연금 전액을 비교해 큰 급여를 자동 선택하고 계산식·기간별 수령표 제공
- 유족연금은 `본인 노령연금 + 산정 유족연금의 30%`와 `본인 노령연금 포기 + 산정 유족연금 100%`를 비교
- 공단 확인 유족연금액이 없을 때 정책 지급률에 따른 자동 추정(확인값 입력 시 우선)
- HTML 보고서 저장, 전략 비교표 CSV 내보내기, Windows 인쇄/PDF 저장
- 기본 저장 없음, 선택 저장 시 AES-GCM 암호화 프로필
- 공개 정책과 사용자 데이터를 분리한 버전 정책 팩
- 프로그램에서 개인정보 없는 AI 정책 업데이트 키트 생성
- AI 정책 JSON의 rule allowlist, 기간, 출처, 범위, 회귀 검증
- 검증 실패 시 AI 수정 요청 키트 생성
- 정책 버전 활성화 및 롤백

## 실행

배포 폴더의 `NpsSimulator.exe`를 실행한다. 앱은 회원가입이나 서버 연결을 요구하지 않는다.

현재 제공되는 것은 개발용 무서명 빌드다. 다른 PC에서는 Windows SmartScreen 경고가 표시될 수 있으며, 정식 배포 전에는 신뢰할 수 있는 코드 서명 인증서로 EXE와 설치 패키지에 서명해야 한다.

### HTML 버전

개발 환경에서는 다음 명령으로 실행한다.

```powershell
cd web
npm install
npm run dev
```

표시되는 `http://localhost:3000`을 연다. 입력값은 브라우저 안에서만 계산하고, 사용자가 세션 저장을 선택하면 AES-256-GCM 암호문만 해당 탭의 `sessionStorage`에 보관한다. 탭을 닫으면 세션 데이터가 사라진다.

다른 사람에게 전달할 때는 `artifacts\CouplePensionSimulator-standalone-v0.1.0.html` 단일 파일만 보내면 된다. 받은 사람은 압축을 풀거나 설치하지 않고 Edge 또는 Chrome에서 파일을 더블클릭한다. 화면과 계산 코드는 파일 안에 포함되며 인터넷 연결을 요구하지 않는다.

## 빌드와 테스트

Windows PowerShell에서 다음을 실행한다.

```powershell
.\build.ps1
```

완료된 독립 실행 파일은 `artifacts\win-x64\NpsSimulator.exe`에 생성된다.

## 개인정보 보호

- 입력값은 사용자가 저장을 선택하기 전까지 파일로 남기지 않는다.
- 프로필은 8자 이상의 사용자 비밀번호로 AES-GCM 암호화한다.
- 정책 업데이트 키트에는 개인 프로필이나 계산 결과가 포함되지 않는다.
- 텔레메트리, 광고, 계정, 클라우드 동기화 기능이 없다.
- HTML·CSV·인쇄/PDF 파일은 평문 민감정보가 될 수 있으므로 사용자가 직접 보관해야 한다.

## 정확도와 한계

현재 연금액 계산은 국민연금공단 예상연금을 기준으로 가입개월 증가분을 비례 추정하는 Anchor Mode다. 추납 비용도 현재 보험료 기준 근사값이다. 세후액은 과세대상 연금 100%, 본인 1인 기본공제, 다른 종합소득 없음으로 가정한 참고값이므로 NPS 앱의 실제 세후 표시값과 다를 수 있다. 실제 추납 가능기간, 보험료, 세금, 수급 자격, 노령·유족연금은 신청 시점 법령과 국민연금공단 산정 결과가 우선한다.

정책 팩만으로 처리할 수 없는 새로운 급여 종류나 계산 개념이 신설되면 프로그램 본체 업데이트가 필요하다.
